1 Apresentação do Projeto

O HiringScope é um marketplace que conecta clientes e prestadores de serviços de forma simples, rápida e segura. A plataforma permite que qualquer pessoa encontre profissionais qualificados para realizar serviços domésticos, técnicos, criativos e muito mais.

Objetivo

Facilitar a contratação de serviços, eliminando intermediários desnecessários e oferecendo uma experiência transparente tanto para quem contrata quanto para quem oferece serviços.

Principais Funcionalidades

👤
Cadastro e Login
Login tradicional e via Google (Firebase Auth).
🔧
Cadastro de Serviços
Prestadores publicam serviços com fotos, preços e descrição.
🔍
Busca Inteligente
Filtros por categoria, cidade e termo de busca.
💬
Chat em Tempo Real
Comunicação direta entre cliente e prestador.
⭐
Avaliações
Sistema de notas e comentários com estrelas.
👑
Planos de Destaque
Prestadores pagam para ter mais visibilidade.
ℹ️ Sobre este documento: Esta documentação cobre desde a visão geral do projeto até guias técnicos de deploy e operação. Use o sumário acima para navegar entre as seções.

2 Como Usar — Guia do Cliente

Este guia mostra o passo a passo para contratar um serviço no HiringScope.

Passo 1: Criar sua Conta

  1. Acesse hiring-scope.com.br
  2. Clique em Cadastrar
  3. Preencha seus dados ou use o botão "Entrar com Google"
  4. Pronto! Sua conta de cliente está criada

Passo 2: Buscar Serviços

  1. Na barra de busca, digite o que você precisa (ex: "eletricista")
  2. Ou navegue pelas categorias disponíveis
  3. Use os filtros para refinar a busca

Passo 3: Conversar com o Prestador

  1. Clique no botão 💬 do serviço que te interessou
  2. O chat abre automaticamente
  3. Negocie valores, prazos e detalhes

Passo 4: Avaliar o Serviço

  1. Após a conclusão, avalie o prestador
  2. Dê uma nota de 1 a 5 estrelas
  3. Escreva um comentário sobre sua experiência
✅ Dica: Sempre verifique as avaliações do prestador antes de contratar. Prestadores com boas notas são mais confiáveis.

3 Como Usar — Guia do Prestador

Este guia mostra como se cadastrar como prestador e começar a ganhar dinheiro no HiringScope.

Passo 1: Cadastro como Prestador

  1. Acesse hiring-scope.com.br
  2. Clique em Cadastrar
  3. Escolha a opção "Sou Prestador"
  4. Preencha seus dados profissionais

Passo 2: Cadastrar seus Serviços

  1. No Dashboard, clique em "Novo Serviço"
  2. Preencha título, descrição e categoria
  3. Defina o preço (fixo, por hora, por dia, por m² ou sob consulta)
  4. Adicione uma foto do serviço
  5. Clique em "Cadastrar"

Passo 3: Destacar seus Serviços

Para aumentar sua visibilidade, assine um dos planos:

Plano Preço Serviços em Destaque Extras
Básico R$ 9,99/mês 1 Selo Premium
Pro R$ 29,90/mês 3 Selo Pro + Prioridade na busca

Passo 4: Receber Clientes

  1. Clientes entrarão em contato pelo chat
  2. Responda rápido para fechar mais negócios
  3. Após o serviço, peça uma avaliação
  4. Boas avaliações = mais clientes
💰 Dica de ouro: Prestadores que respondem em até 1 hora têm 3x mais chances de fechar o serviço. Ative as notificações no seu celular!

5 Arquitetura do Sistema

O HiringScope é uma aplicação monolítica em Flask, organizada em blueprints para separação de responsabilidades.

Visão Geral

┌─────────────────────────────────────────┐
│         NAVEGADOR (Cliente)             │
│  HTML + CSS + JS + Socket.IO            │
└─────────────────┬───────────────────────┘
                  │ HTTPS
                  ▼
┌─────────────────────────────────────────┐
│         FLASK (Railway)                 │
│  ┌───────────────────────────────────┐ │
│  │ Blueprints (routes/)              │ │
│  │ - auth, main, servico, chat       │ │
│  │ - contrato, admin, assinatura     │ │
│  └───────────────────────────────────┘ │
│  ┌───────────────────────────────────┐ │
│  │ Services (services/)              │ │
│  │ - mercado_pago_service            │ │
│  └───────────────────────────────────┘ │
│  ┌───────────────────────────────────┐ │
│  │ Models (models.py)                │ │
│  │ - Usuario, Servico, Contrato...   │ │
│  └───────────────────────────────────┘ │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│       BANCO DE DADOS (SQLite)           │
│  Volume persistente no Railway          │
└─────────────────────────────────────────┘

Fluxo de Autenticação

  1. Usuário clica em "Entrar com Google"
  2. Frontend chama Firebase Auth (JavaScript)
  3. Firebase retorna um idToken
  4. Frontend envia idToken para /auth/firebase/callback
  5. Backend verifica idToken com Firebase Admin SDK
  6. Backend cria/recupera usuário no banco
  7. Backend cria sessão Flask-Login

Fluxo de Pagamento

  1. Prestador clica em "Assinar Plano"
  2. Backend cria uma "preference" no Mercado Pago
  3. Backend retorna URL de checkout
  4. Prestador é redirecionado para o Mercado Pago
  5. Após pagamento, MP redireciona para /assinatura/sucesso
  6. Backend ativa a assinatura e o destaque
  7. MP também envia webhook para /assinatura/webhook

Fluxo do Chat

  1. Cliente clica em "Conversar" no card do prestador
  2. Função iniciarChat() salva dados no sessionStorage
  3. Redireciona para /chat/
  4. Página do chat verifica sessionStorage e abre conversa
  5. Mensagens são enviadas via POST /chat/enviar
  6. WebSocket (Socket.IO) entrega em tempo real
  7. Fallback: polling a cada 4 segundos

8 Guia de Deploy

Pré-requisitos

  • Conta no Railway (plano Hobby)
  • Conta no Mercado Pago Developers
  • Conta no Firebase
  • Domínio registrado (Registro.br)
  • DNS configurado (Cloudflare)

Passo 1: Deploy no Railway

  1. Acesse railway.app
  2. Conecte ao GitHub
  3. Selecione o repositório Hiring_Scope_TG2
  4. Adicione as variáveis de ambiente (ver .env.example)
  5. Aguarde o deploy automático

Passo 2: Banco de Dados

  1. No Railway, crie um Volume montado em /app/instance
  2. O SQLite será persistido automaticamente

Passo 3: Firebase

  1. Acesse console.firebase.google.com
  2. Authentication → Settings → Authorized domains
  3. Adicione: hiring-scope.com.br e www.hiring-scope.com.br

Passo 4: Mercado Pago

  1. Acesse mercadopago.com.br/developers/panel/app
  2. Copie o Access Token de produção
  3. Adicione no Railway como MERCADOPAGO_ACCESS_TOKEN

Passo 5: Domínio Customizado

  1. Registro.br → Altere os Nameservers para os do Cloudflare
  2. Cloudflare → Adicione os registros CNAME apontando para o Railway
  3. Aguarde a propagação (1-2 horas)

9 Backup e Recuperação

Backup Manual

Faça backup do banco de dados semanalmente:

# No Console do Railway:
railway volume files download /app/instance/prestadores.db ./backups/backup_2026-10-07.db

Backup Automático

  1. No Railway, acesse a aba Backups
  2. Ative o Daily Backup (mantido por 6 dias)
  3. Ative também o Weekly Backup (mantido por 27 dias)

Restaurar Backup

# Enviar backup para o Railway:
railway volume files upload ./backups/backup_2026-10-07.db /app/instance/prestadores.db

# Depois, no painel do Railway:
# Settings → Restart
⚠️ Atenção: Nunca delete o Volume do Railway. Isso apagaria todos os dados permanentemente, incluindo os backups automáticos.

10 Solução de Problemas

Erro: "The default Firebase app does not exist"

Causa: A variável FIREBASE_CREDENTIALS não está configurada.

Solução: Adicione o JSON da service account no Railway.

Erro: "MERCADOPAGO_ACCESS_TOKEN não configurado"

Causa: A variável de ambiente está faltando ou tem nome errado.

Solução: Certifique-se de que o nome é exatamente MERCADOPAGO_ACCESS_TOKEN (sem underline entre MERCADO e PAGO).

Erro: "The train has not arrived at the station"

Causa: Domínio não propagou ainda ou SSL não foi emitido.

Solução: Aguarde 1-2 horas. Se persistir, desligue o Proxy do Cloudflare temporariamente.

Chat não carrega mensagens

Causa: Função iniciarChat não definida ou sessionStorage vazio.

Solução: Verifique se o base.html tem a função iniciarChat no escopo global.
